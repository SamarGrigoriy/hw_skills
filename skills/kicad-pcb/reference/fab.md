# Профили технологических норм, стек и число слоёв

Профиль выбирается на этапе 1 вместе с человеком и записывается в карту
требований. Молча профиль не выбирается: нормы разных заводов отличаются так,
что плата под один завод может не пройти входной контроль другого.

## Предельные и рекомендованные нормы

У каждого профиля два столбца. **Предел** — то, что завод обещает сделать.
**Рекомендовано** — то, что скилл пишет в правила платы. Разводка на пределе
снижает выход годных, дорожает при доплатах за мелкие отверстия и мешает
ремонту. Предел используется только локально — выход из корпуса с мелким
шагом — и записывается в описание платы правилом для этой зоны.

## Резонит

**Не заполнен.** Значения не сверялись. Перед первым проектом под этот завод
взять их со страницы технологических возможностей завода
(https://www.rezonit.ru/directory/tekhnologicheskie-osobennosti-proizvodstva/)
и справочника рекомендаций к конструкции, внести сюда с датой сверки и
столбцами «Предел» и «Рекомендовано». Пока профиль пуст, плата под Резонит не
разводится: скилл говорит об этом человеку, а не подставляет нормы другого
завода.

## Как добавить профиль

1. Новый раздел с названием завода, ссылкой на страницу и датой сверки.
2. Та же таблица параметров; неизвестное значение — «не указано», а не
   догадка.
3. Рекомендованные значения не мельче рекомендованных JLCPCB без причины.

## Стек двухслойной платы

| Толщина | `h`, мм | Микрополосок 50 Ом | Жёсткость | Когда |
|---|---|---|---|---|
| 1,6 мм | ≈ 1,5 | ≈ 3 мм | лучшая | по умолчанию; тяжёлые выводные детали, клеммники, держатели банок |
| 1,0 мм | ≈ 0,9 | ≈ 1,7 мм | средняя | ВЧ-линии и плотная разводка при лёгких деталях |
| 0,8 мм | ≈ 0,7 | ≈ 1,3 мм | низкая | малые платы без тяжёлых деталей |

Ширины — ориентир для микрополоска на FR4; для копланарной линии с землёй и
точных значений — расчёт по `emc.md`, раздел 6. Меньшая `h` прижимает обратный
ток к дорожке и уменьшает петли, но плата гнётся под винтами и держателями.
Толщина — вопрос карты требований.

## Число слоёв

**По умолчанию — 2.** Переход на 4 слоя — **только с согласования человека**.
Скилл сам слои не добавляет, даже если плата не разводится.

### Когда поднимать вопрос

Признаки перечислены в `emc.md`, раздел 13. Вопрос поднимается, только когда
испробовано всё, что не требует решения человека: раздвижка размещения,
увеличение контура в пределах корпуса, перестановка блоков.

### Как спрашивать

Вопрос должен позволять решить одной строкой. В нём:

1. Что не проходит: правила, цепи, место на плате, картинка узкого места.
2. Что уже испробовано и почему не помогло.
3. Сравнение вариантов:

| | 2 слоя с раздвижкой | 2 слоя с исключением | 4 слоя |
|---|---|---|---|
| размер платы | | | |
| цена партии по калькулятору завода на сегодня | | | |
| остаточные риски ЭМС | | | |
| что меняется в корпусе и сборке | | | |

4. Рекомендация скилла и её причина.

### После решения

Ответ записывается в карту требований и в описание платы с датой. Если выбраны
4 слоя, стек по умолчанию: сигнал — сплошная земля — питание и медленные
сигналы — сигнал; разводка начинается заново с этапа 3, пороги `emc.md` для
B.Cu переносятся на внутренний слой земли.
