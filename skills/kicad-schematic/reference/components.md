# Подбор компонентов из каталога Промэлектроники

Каталог — товары **в наличии** на www.promelec.ru по разделам, актуальным для
разработки: микросхемы, дискретные, пассивные, разъёмы, защита, модули, датчики,
питание, средства отладки, корпуса. Электрощитовое, светотехника, инструмент и
отечественные силовые приборы в него намеренно не входят.

| Где | Что |
|---|---|
| `~/Proj/3.Resourses/components/promelec/catalog.db` | SQLite, по нему ищет `partfind.py` |
| `~/Proj/3.Resourses/components/promelec/by_category/` | CSV по разделам `<L1>/<L2>/<L3>.csv` — открыть глазами |
| `~/Proj/3.Resourses/components/promelec/README.md` | сводка: сколько, когда собрано, что не спарсено |
| `~/Proj/3.Resourses/parser/` | парсер; `selection.py` — список разделов |

## Порядок подбора

1. **Сформулировать требования до поиска**: электрические параметры с запасом,
   корпус под монтаж, температурный диапазон, партия. Без этого поиск превращается
   в выбор «самого популярного», а он редко самый подходящий.
2. **Найти раздел**: `partfind.py cats <слово>` → ключ вида `1/15/108`.
   Одна и та же деталь бывает в двух разделах — ищи по ветке (`--cat 1/15`).
3. **Посмотреть, по чему фильтровать**: `partfind.py params 1/15/108` — имена
   параметров и частые значения. Имена берутся как есть с сайта.
4. **Отфильтровать**: `partfind.py find "" --cat 1/15/108 -p "Корпус=SOT-23" --min-stock 300 --sort price`.
   Параметры на сайте заполнены не у всех товаров: у микроконтроллеров STM
   ядро указано примерно у трети. `-p` отсекает товары без параметра, поэтому
   пустой результат с `-p` повторить поиском по тексту описания
   (`find "cortex m0+" --cat 1/11/1777`), прежде чем решать, что детали нет.
5. **Проверить карточку**: `partfind.py show <имя>` — все параметры, ссылка на
   товар. Даташит сверять по ссылке, параметры каталога — только для отбора.
6. **Склад ≥ количество на плату × партия**, с запасом на брак. Иначе деталь
   формально есть, а партию не собрать.
7. **Аналог тоже из каталога**, по возможности другого производителя и с тем же
   посадочным местом.

## Если подходящего нет

**Остановиться и сказать пользователю.** Не подставлять деталь по памяти, не
брать молча «почти подходящую», не уходить к другому поставщику без согласия:
допарсить раздел или найти деталь в другом магазине решает и делает он.
Вопрос должен позволять ответить одной строкой:

> Для U3 (LDO 3,3 В, Iq < 1 мкА, ≥ 150 мА, SOT-23) в каталоге Промэлектроники
> ничего нет. Искал: 1/15/108, «Корпус=SOT-23», склад ≥ 300.
> Ближе всего: XC6206P332MR — Iq 1 мкА (в 40 раз больше); HT7333 — корпус SOT-89.
> Варианты: (1) взять XC6206, автономия упадёт с сезона до ~4 месяцев;
> (2) перепарсить раздел — данным 35 дней; (3) заказать TPS7A05 у другого поставщика.

## Если раздела нет или данные устарели

`partfind.py cats` показывает, спарсен ли раздел и сколько дней данным.
Раздел не спарсен, устарел или его нет в дереве — **сказать пользователю** тем же
вопросом, что и при отсутствии детали. Допарсивает раздел или ищет деталь в других
магазинах он сам; парсер по своей инициативе не запускать.

Справка для пользователя (команды в `~/Proj/3.Resourses/parser/`):

| Ситуация | Команда |
|---|---|
| раздел в дереве есть, не спарсен или устарел | `venv/bin/python parse_products.py --only <ключ>` |
| раздела нет в дереве вовсе | `venv/bin/python parser_category.py`, затем `--only` |
| раздел будет нужен и дальше | дописать ключ в `selection.py` |

Сайт закрыт DDoS-Guard и это чужой магазин: только нужный раздел, не параллельно,
паузы не уменьшать, `/search/` и `sort` не трогать (robots.txt), на 403 — ждать.

## Прямой SQL

Для запросов, которых нет в `partfind.py`:

```sql
-- categories(key, l1_name, l2_name, l3_name, path, count_total, count_instock, parsed_at, complete, selected)
-- products(good_id, name, description, brand, package, price, stock, external_stock, url, category_key, params_json, parsed_at)
-- product_categories(good_id, category_key)   params(good_id, name, value)
SELECT p.name, p.price, p.stock, pr.value
FROM products p JOIN params pr ON pr.good_id = p.good_id AND pr.name = 'Выходной ток'
WHERE p.category_key = '1/15/108' AND p.stock >= 300
ORDER BY p.price;
```

`stock` — склад Промэлектроники, `external_stock` — внешние склады (срок поставки
дольше). Значения параметров — строки как на сайте («2 В ~ 3.6 В»), сравнивать
их как числа нельзя без разбора.
